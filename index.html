FILE VERIFICATION

Drop the original file and its .ots proof. ProofStamp checks the Bitcoin blockchain and tells you when the file existed – and whether it has been changed.

Tip: you can also drop both files at once into either box.

How it works

1. Fingerprint
Your browser calculates a unique SHA-256 code. Change one letter in the file and it is completely different.
2. Stamp
Only the fingerprint goes to the free OpenTimestamps servers, which write it into Bitcoin. You keep a small .ots proof file.
3. Bitcoin confirms
After a few hours your proof sits in a Bitcoin block. Anyone can check it on the Verify page – no notary, company or government needed.

Private by design: your file is never uploaded. Only its fingerprint leaves your computer, and the file cannot be rebuilt from it.

Tip: on a Mac, .ots files may show up as "OpenDocument Template". That is just a name clash with another program – don't open them, simply keep them.
